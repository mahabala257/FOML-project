# FOML Mini Project

## 📌 Project Overview

This repository contains the mini project developed for the **Foundations of Machine Learning (FOML)** course. The project focuses on applying machine learning techniques to analyze data, build predictive models, and evaluate their performance.

## 🎯 Objectives

* Understand the dataset and its features.
* Perform data preprocessing and cleaning.
* Apply machine learning algorithms.
* Evaluate model performance using suitable metrics.
* Document the findings and conclusions.

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
cd <repository-folder>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

Run the notebook or Python script:

```bash
jupyter notebook
```

or

```bash
python main.py
```
